# Подключение робота и установка приложения

Практическая инструкция по опыту первых запусков на GreetingBot Nova (OrionStar OS 10.4 OS-R-SG). Подробности про ADB, VPS и CI — в [`infra/README.md`](../infra/README.md).

## 1. Что важно знать о роботе

- На роботе **RobotOS 10.4**, а не AgentOS V12.6. Поэтому используется вариант сборки **`robotos`** (`robotservice.jar`). Вариант `robot` (AgentOS SDK) здесь не запустится.
- Приложение получает доступ к карте, навигации, голосу и камере, **только если запущено через RobotOS Home** (список приложений робота). Запуск из браузера, из уведомления об установке или из Android Studio не даёт этих прав.
- Настройки отладки применяются **только после перезагрузки** робота.

## 2. Сеть

Ноутбук с сервером и робот должны быть **в одной сети**.
- Самый надёжный вариант для тестов — **раздача Wi-Fi с телефона**, к которой подключены оба. В гостевых и корпоративных сетях устройства часто не видят друг друга.
- **IP робота:** настройки Wi-Fi робота, список подключённых устройств на телефоне или поиск с ноутбука по MAC робота: `ip neigh` после `ping` всей подсети.
- **Firewall на ноутбуке** (если включён `ufw`) должен пускать робота к серверу (8000) и к раздаче APK (8090):
  ```bash
  sudo ufw allow from <подсеть, например 10.54.180.0/24> to any port 8000,8090 proto tcp
  ```
- В некоторых сетях заблокирован API Gemini: соединение рвётся на TLS-рукопожатии. Проверка: `curl -sS https://generativelanguage.googleapis.com/` должен вернуть HTTP-ответ, а не `Connection reset`. В эксплуатации это решает сервер на VPS за рубежом.

## 3. Установка APK

### Способ A: через браузер робота (без ADB)
1. Собрать APK и раздать его с ноутбука:
   ```bash
   cd android-app && ./gradlew publishTestApks          # → ~/astana-hub-apk/
   python3 -m http.server 8090 --bind 0.0.0.0 --directory ~/astana-hub-apk
   ```
2. На роботе открыть браузер и перейти на `http://<IP-ноутбука>:8090/astana-hub-robotos.apk`.
3. Установить. Если спросит про неизвестные источники, разрешить. Новая версия ставится поверх старой.
4. Запустить **из списка приложений робота**.

### Способ B: по ADB
1. На роботе одним пальцем провести от верхнего края вниз, 10–15 раз быстро тапнуть по времени и ввести **динамический пароль** (выдаёт OrionStar по SN робота, он привязан ко времени).
2. Включить **Enable debugging (启用调试)**, затем **Persistent debugging (持久调试)**, а если есть, то и **Wi-Fi ADB**. В том же меню есть кнопки «Открыть настройки» и «Включить системную панель навигации».
3. Перезагрузить робота.
4. Подключиться и установить:
   ```bash
   adb connect <IP-робота>:5555
   adb install -r ~/astana-hub-apk/astana-hub-robotos.apk
   ```
   Или кабелем micro-USB в разъём на голове робота. Нужен кабель с передачей данных.

Признак того, что отладка не включилась: `adb connect` отвечает `Connection refused`, при этом робот пингуется. Открытые порты робота 6670, 6671, 7890 и 9191 — это его внутренние службы, а не ADB.

## 4. Первая настройка в приложении

Экран диагностики открывается **долгим нажатием на надпись «Astana Hub»**.

1. **Адрес сервера:** ввести `<IP-ноутбука>:8000`, нажать «Проверить» (должно быть OK) и «Сохранить». При смене сети достаточно поменять адрес, переустанавливать приложение не нужно.
2. **Масштаб интерфейса:** подобрать ползунком (60–150 %) и сфотографировать блок с метриками экрана.
3. **Голос:**
   - кнопки теста встроенного TTS (RU/KZ/EN): говорит ли робот;
   - «Движки и языки»: какие языки поддерживает встроенный синтез;
   - запись фразы и уровень микрофона: даёт ли робот приложению микрофон;
   - переключатели распознавания и озвучки по языкам.
4. **Карта:** статус RobotApi (подключено или нет), кнопки «getPlaceList» и «getPosition». Названия точек карты нужны для базы мест на сервере (`map_name`).

## 5. Чек-лист первой проверки

- [ ] RobotApi подключён (статус на экране диагностики)
- [ ] встроенный TTS говорит по-русски
- [ ] уровень микрофона растёт, когда говоришь
- [ ] вопрос голосом → распознан → ответ озвучен
- [ ] «Где ресепшен?» называет направление (нужна карта с точками)
- [ ] «Проводи» → робот едет, «Стоп» останавливает
- [ ] «Что это?» → описание помещения
- [ ] интерфейс помещается на экране 14" при масштабе 100 %
- [ ] через 60 с бездействия включается заставка
- [ ] автозапуск: Settings (свайп тремя пальцами вниз) → Developer settings → Startup programs → Astana Hub

Результаты записывать в `docs/spikes/` (шаги 2.3–2.8 roadmap).
