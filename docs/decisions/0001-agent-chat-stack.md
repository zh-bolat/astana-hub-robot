# ADR 0001: стек агентского чата

**Статус:** принято · **Дата:** 2026-10-21 · **Решил:** Bolat (владелец проекта)

## Контекст
Текущий `/v1/ask` отвечает на одну реплику: правила на роботе (`IntentRouter`) решают, что делать, сервер не помнит разговор и не умеет уточнять. Нужен агент: модель сама выбирает действие (база знаний, «где X», «проводи», камера), помнит разговор, задаёт уточняющие вопросы, отвечает голосом на RU/KZ/EN.

## Решение
| Слой | Выбор |
|---|---|
| Каркас агента | **OpenAI Agents SDK** (Python) внутри нашего `backend/` |
| Модель агента и зрения | **Claude Haiku 5.5** (`claude-haiku-5-5`) через `LitellmModel` расширения SDK |
| Голос (TTS) | **ElevenLabs**: `eleven_v3` для kk, `eleven_flash_v2_5` для ru/en (модуль уже есть в backend) |
| Распознавание речи (STT) | без изменений: Gemini (`/v1/stt`); замена — отдельным решением после сравнения |
| Тулы | `search_knowledge`, `find_place` / `where_is`, `guide_to`, `look` — наши функции (`@function_tool`); никаких shell/файлов/браузера |
| Память | наши таблицы `sessions` / `messages` в Postgres (`docs/db-schema.md`) |
| Защита | guardrails SDK + существующий выходной фильтр и лимиты из волны 1 |
| API для робота | новый эндпоинт `/v1/chat` (сначала фиксируется в `docs/api-contract.md`); `/v1/ask` остаётся запасным путём |

## Обязательные условия
1. **Трассировка SDK выключена** (`set_tracing_disabled(True)` / `OPENAI_AGENTS_DISABLE_TRACING=1`): иначе тексты вопросов посетителей уходят в OpenAI. Ключ OpenAI для работы не нужен.
2. **Ключи** (Anthropic, ElevenLabs) — только на сервере, в `infra/.env`.
3. **Проверить на спайке:** работает ли кеш промпта Claude (база знаний) через `LitellmModel`; задержка до первой фразы; качество kk; корректный вызов тулов. Если кеш не работает или задержка выше ~3 с — вернуться к выбору каркаса (альтернатива: Anthropic SDK Tool Runner).
4. Pipecat (живой голос в реальном времени) — не сейчас; агент подключается к нему позже без переписывания.

## Рассмотренные альтернативы
- **Anthropic SDK Tool Runner** — нативно для Claude (кеш промпта, настройки скорости), но без готовых guardrails/handoffs и только для Claude.
- **Свой цикл на Gemini function calling** — без зависимостей, но выбран Haiku 5.5.
- **OpenClaw** — отклонён: модель получает права ОС, серьёзная история уязвимостей, не та задача.
- **OpenAI Realtime API / Gemini Live** — голос модели вместо ElevenLabs, казахский не проверен.

## Последствия
- Новые зависимости backend: `openai-agents`, `litellm`.
- Новый провайдер модели — Anthropic; Gemini остаётся для `/v1/stt` и как резерв `/v1/ask`.
- Нужны ключи: Anthropic (Haiku 5.5), ElevenLabs.

## Реализация (2026-10-23): сервер
Сделано: `POST /v1/chat` (контракт — `docs/api-contract.md`), код — `backend/app/agent/`. Приложение пока ходит в `/v1/ask`.

Отступления от решения:
- **Haiku через OpenRouter, а не прямой ключ Anthropic** (решение владельца проекта 2026-10-23). Модель —
  `anthropic/claude-haiku-5.5`; в SDK она подключена через `OpenAIChatCompletionsModel` (OpenRouter
  OpenAI-совместим), а не `LitellmModel`: `litellm` не нужен. Прямой ключ Anthropic можно вернуть позже через `LitellmModel`.
- **Тула `search_knowledge` нет**: база маленькая (~4,5 тыс. токенов), целиком лежит в системном промпте под кешем;
  отдельный тул только добавил бы запрос к модели. Вернётся вместе с векторным поиском (шаг 2 `docs/db-schema.md`).
- Тулы — действия робота: `where_is`, `guide_to`, `look`; плюс `no_answer` (вопрос без ответа → отказ и строка
  «без ответа» в логе). После `look` и `no_answer` модель не вызывается повторно, фразу подставляет сервер.

Условия решения, результаты спайка (живые запросы, 2026-10-23):
1. Трассировка выключена: `set_tracing_disabled(True)` и `RunConfig(tracing_disabled=True)`.
2. Ключи — только на сервере (`OPENROUTER_API_KEY`).
3. Кеш промпта работает: с `cache_control: ephemeral` (OpenRouter → Anthropic) из ~4 500 входных токенов
   ~4 510 читаются из кеша. Без `cache_control` кеша нет.
   Задержка до первой фразы: ~1,1–1,5 с на обычный вопрос, ~2–2,6 с с действием (`where_is` / `guide_to`: два
   запроса к модели); первый запрос после простоя — до ~2,8 с. Порог 3 с выдержан.
   Размышления Haiku выключены (`reasoning.enabled=false`): с ними первая фраза 2–5 с, и при лимите токенов
   казахский ответ обрывался.
   Казахский — грамотный, тулы вызываются верно (проводы — 10 из 10 на повторном прогоне).
4. Pipecat — не делали.

Найдено на спайке и закрыто в коде:
- без размышлений модель иногда «думает» текстом («The visitor asks…») — текст ответа, в котором есть вызов тула,
  не озвучивается, а фразы-рассуждения отсекает фильтр (`agent_narration_dropped` в логе);
- память пишется в БД фоном, а следующий вопрос приходит сразу после `done` — история берётся из кеша в памяти
  процесса (БД — после перезапуска сервера). Это рассчитано на один процесс uvicorn, как в `Dockerfile`.
