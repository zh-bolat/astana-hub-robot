- `backend/knowledge/facts.yaml` — 61 факт ru/kk/en (вместо 13 заглушек). Id старых фактов сохранены (`wifi`, `hours`, `cafe`, `coworking`, `residency`, `parking`, `toilet`, `meeting_rooms`, `accelerator`…), eval-вопросы остаются валидными.
- `backend/knowledge/sheet_template/facts.csv` — то же для вкладки «Факты» Google-таблицы (пересобирается из YAML, тест `test_template_equals_yaml_examples`).
- `backend/knowledge/pronunciations.yaml` — как TTS читать новые названия: Hub Space, Tech Orda, alem.ai, почты, LRT и т. д.
- `places.yaml` и `quick_questions.yaml` не менялись: места сняты с карты робота.

Не включено намеренно (устарело, противоречиво или не для озвучки): поминутный коворкинг TimeApp (25 ₸/мин, 2024 — страница сейчас 404), старые тарифы Hub Space 60/80 тыс., цены парковки 2017 года, выручка $907 млн за I квартал 2026, WhatsApp из 2GIS, личные контакты сотрудников хаба.

## Как залить на сервер

Вариант 1 — YAML (папка `knowledge/` вшита в Docker-образ):
1. Задеплоить бэкенд с новыми файлами (пересборка образа).
2. `docker compose exec api python -m app.cli kb seed-yaml` — upsert в Postgres, факты, которых нет в YAML, выключаются.
3. `docker compose exec api python -m app.cli kb status` — проверить `facts=61`.

Вариант 2 — Google-таблица: импортировать `sheet_template/facts.csv` во вкладку «Факты», синк подхватит сам (`KNOWLEDGE_SHEET_ID`).

`pronunciations.yaml` читается из `KNOWLEDGE_DIR` и приезжает только с образом (вариант 1).

## Вопросы к сотрудникам хаба

1. План 1 этажа C4.6 (холл робота): ресепшен, вход, залы, TikTok Space, кафе, санузлы, лифт, лестница. В открытом доступе его нет.
2. Гостевой Wi‑Fi: есть ли, имя сети, как подключиться.
3. Часы ресепшена для гостей, работа в выходные и праздники.
4. Может ли частное лицо разово поработать в коворкинге, где и сколько стоит.
5. Какое кафе на карте робота (`cafe`), что за точка `snacks`, их часы.
6. Работает ли TikTok Space и как туда записаться.
7. Тариф паркинга, есть ли бесплатные места для гостей.
8. Экскурсии: дни, размер группы, языки, контакт.
9. Цены аренды залов для сторонних организаторов.
10. Срок рассмотрения заявки участника: 15 или 25 рабочих дней; база членского взноса 1%.
11. Какую цифру экспорта 2025 называть официальной: $634 млн (хаб) или ~$681 млн (министр).
12. Есть ли гардероб, камера хранения, бюро находок, медпункт, курилка в C4.6.
