## Сценарии

### Вопрос о хабе
1. Речь посетителя распознаётся: по умолчанию на сервере (`/v1/stt`, Gemini), опционально встроенным ASR робота.
2. `IntentRouter` решает, что это обычный вопрос, и приложение вызывает `/v1/ask` со стримингом (SSE).
3. Сервер передаёт Gemini всю базу знаний (на MVP она целиком помещается в контекст) с инструкцией: отвечать только по базе, 1–3 предложения, на языке вопроса.
4. Фразы (≤ 300 символов, ограничение TTS робота) приходят событиями `phrase`, робот начинает говорить по первой.
5. Если ответа в базе нет, `found=false` и вежливый отказ «обратитесь на ресепшен». Вопрос попадает в лог как «без ответа».

### «Где X?», «Проводи», «Где я?»
Работают **без сервера и без интернета**:
- места и синонимы берутся из `/v1/places` (кеш в файле с ETag) и из точек карты робота (`getPlaceList`);
- `PlaceMatcher` находит место по названию на трёх языках, синонимам, с учётом падежей и опечаток;
- направление и расстояние считаются от `getPosition` робота: «справа от вас, метров 15». Считается, что посетитель стоит лицом к роботу;
- «Проводи» запускает `startNavigation`, «Стоп» её отменяет.

### «Что это?»
`SurfaceShareApi` даёт один кадр 640×480, приложение сжимает его в JPEG и отправляет в `/v1/look` вместе с ближайшей точкой карты. Сервер просит Gemini vision описать кадр с подсказкой из описания места. Кадр не сохраняется и не логируется.

## Голос

Распознавание и озвучка выбираются **по языку** и меняются на экране диагностики без пересборки.

| | RU | EN | KZ |
|---|---|---|---|
| Распознавание (по умолчанию) | сервер (Gemini) | сервер | сервер |
| Озвучка (по умолчанию) | встроенный TTS робота | встроенный | сервер `/v1/tts` |

- Если сервер отвечает на `/v1/tts` заголовком `X-Speech-Provider: fake` или ошибкой `503`, робот говорит встроенным голосом.
- На сервере провайдеры задаются через `STT_PROVIDER` / `TTS_PROVIDER` (`auto` по умолчанию). В режиме `auto` порядок такой: STT — ElevenLabs → Gemini → fake, TTS — ElevenLabs → Yandex → fake.
- У ElevenLabs казахский синтез есть только в модели `eleven_v3`, русский и английский идут через быструю `eleven_flash_v2_5`.

## Варианты сборки (flavors)

| Flavor | Для чего | Железо | Встроенный голос |
|---|---|---|---|
| `emulator` | разработка в эмуляторе | заглушки: карта из 5 точек, синтетический кадр | Android TextToSpeech |
| `robotos` | **наш робот, RobotOS 10.4** | `robotservice.jar` (из OrionStar RobotSample): RobotApi, SurfaceShareApi | SkillApi (`playText`) |
| `robot` | роботы на AgentOS V12.6 | AgentOS SDK 0.4.12 | AgentOS |

Код, общий для `robot` и `robotos`, лежит в `app/src/robotShared/`. Выбор реализации — в `di/FlavorGateways.kt` каждого flavor.

## Устойчивость

- **Gemini**: основная модель `gemini-3.1-flash-lite`, резервная `gemini-3.5-flash`. Повтор и резерв срабатывают при 503 / 429 / таймауте. Бюджет укладывается в таймауты робота: 8 с для `/ask`, 12 с для `/look`.
- **Нет сети**: «где / проводи / где я» продолжают работать, на остальное робот честно говорит «нет связи». Фразы ошибок хранятся в приложении.
- **База знаний**: если синхронизация с таблицей не удалась, сервер остаётся на последней удачной версии (снимок на диске).
