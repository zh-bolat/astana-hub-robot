- Режим legacy (диагностика → «Разговор: legacy»): «бодрый» экран — меню (`awakeMode`, как раньше), лицо — во сне
  и в поездке. В M3 решить: лицо — всегда экран 1.
- Подсказка where_is (направление) пока видна только на прежнем экране — остров на экране 1 в M4.
- Тап / поглаживание / long press по лицу — M2. Диагностика — удержанием логотипа на прежнем экране.
- Сон: таймер бездействия пока прежний (`SCREENSAVER_SECONDS`, 60 с); 3 минуты из брифа — в M2.
- Проверить на роботе: Visualizer на MediaPlayer (рот по MP3 TTS), пороги голоса по микрофону Nova, fps на железе.
- Скачок яркости при переходе в прежнее светлое меню (ревью M1-r1, M1) — уйдёт в M3 (экран 2 тёмный).
- screenrecord на эмуляторе теряет кадры при частых `am broadcast` (записи 40–46 fps); плавность приложения —
