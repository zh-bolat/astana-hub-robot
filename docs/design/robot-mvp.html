Робот-гид Astana Hub: прототип экрана

Версия 4: главная страница целиком лицо робота (чёрный экран, голубые глаза, мимика с листа эмоций). Касание открывает белые страницы приложения, а лицо сжимается и собирается в робота слева. Поведение как в main: Робот отвечает с лицом на весь экран, касание лица открывает привычную страницу, а речь продолжается. Выйти из приложения можно только по PIN сотрудника. Нажимайте на экран как на сенсорный, голос и подход посетителя имитирует панель ниже.

Панель демо (на роботе её нет)

Тексты ответов, места и расстояния здесь примерные, не данные хаба. На роботе ответы приходят с сервера. Через 20 с без действий после ответа экран сам возвращается к приветствию, через 60 с на приветствии включается заставка. В режиме agent меню без касаний через 30 с снова сменяется лицом, а в режиме legacy лицо появляется только на время ответа. PIN для выхода в прототипе: 0000 (в приложении PIN задаётся в secrets.properties).
