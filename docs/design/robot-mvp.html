Робот-гид Astana Hub: прототип экрана

Версия 4: главная страница целиком лицо робота (чёрный экран, голубые глаза, мимика с листа эмоций). На странице с лицом только мимика. Свайп по лицу (мышкой: потяните его) сжимает его в робота слева и открывает белые страницы приложения. Поведение как в main: Робот отвечает с лицом на весь экран, свайп по лицу открывает привычную страницу, а речь продолжается. Выйти из приложения можно только по PIN сотрудника. Нажимайте на экран как на сенсорный, голос и подход посетителя имитирует панель ниже.

Панель демо (на роботе её нет)

Тексты ответов, места и расстояния здесь примерные, не данные хаба. На роботе ответы приходят с сервера. Через 20 с без действий после ответа экран сам возвращается к приветствию, через 60 с на приветствии включается заставка. В режиме agent меню без касаний через 90 с снова сменяется лицом; касание лица робота открывает лицо на весь экран, а в режиме legacy лицо появляется только на время ответа. Пароль для выхода в прототипе: 0000 (в приложении он задаётся в secrets.properties).
